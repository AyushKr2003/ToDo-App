# ToDo App

A Flutter application for managing your daily tasks and to-dos.

## Features

- Create and manage todo items
- Mark tasks as completed/uncompleted
- Delete tasks
- Clean and intuitive user interface with custom styling
- Cross-platform support (Android, iOS, Web, Desktop)

## Project Structure

The app follows a clean architecture with separate directories for:

- `lib/constants/` - App-wide constants like colors
- `lib/model/` - Data models (Todo item model)
- `lib/screens/` - UI screens/pages
- `lib/widgets/` - Reusable UI components
- Platform-specific directories for Android, iOS, Web and Desktop support

## Getting Started

This project is built with Flutter. To get started:

1. Make sure you have Flutter installed on your system. For installation instructions, check out the [official Flutter documentation](https://docs.flutter.dev/get-started/install)

2. Clone this repository 

3. Get dependencies:
```bash
flutter pub get
```

4. Run the app:
```bash
flutter run
```
